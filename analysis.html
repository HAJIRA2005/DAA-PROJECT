Algorithm Performance Analysis

Time Complexity Comparison

Fisher-Yates Shuffle (Las Vegas)

Time Complexity: O(n)

Correctness: Guaranteed uniform permutation

Performance: Optimal for generating random arrangements

Randomised Selection (Las Vegas)

Time Complexity: O(n) average, O(n²) worst

Correctness: Always finds correct k-th element

Performance: Efficient for finding lottery patterns

Monte Carlo Sampling

Time Complexity: O(n)

Correctness: High probability correctness

Performance: Excellent for approximations and simulations

Key Insights from Analysis

Uniform Distribution

Randomised algorithms produce nearly uniform distributions when using proper random generators. Numbers appear with approximately equal frequency.

Entropy & Randomness

High entropy indicates good randomness. The lottery system should have high entropy to ensure unpredictability and fairness.

Law of Large Numbers

As iterations increase, the observed frequency distribution converges to theoretical uniform distribution, validating our randomised algorithms.

Efficiency Trade-offs

Monte Carlo methods provide fast approximations while Las Vegas algorithms guarantee correctness, each suited for different scenarios.
