Randomised Algorithms

Understanding algorithms that use randomness to solve computational problems

1. Randomised Quick Sort

Average: O(n log n)

Description

Randomised Quick Sort selects a random pivot element instead of choosing from a fixed position. This helps avoid worst-case scenarios where the pivot divides the array poorly.

Pseudocode

RANDOMIZED-QUICKSORT(A, p, r)
    if p < r
        q = RANDOMIZED-PARTITION(A, p, r)
        RANDOMIZED-QUICKSORT(A, p, q-1)
        RANDOMIZED-QUICKSORT(A, q+1, r)

RANDOMIZED-PARTITION(A, p, r)
    i = RANDOM(p, r)
    exchange A[r] with A[i]
    return PARTITION(A, p, r)

Analysis

  • Worst Case: O(n²)
  • Average Case: O(n log n)
  • Space Complexity: O(log n) - due to recursion
  • Advantages: Eliminates worst-case input patterns

2. Randomised Selection

Average: O(n)

Description

This algorithm finds the k-th smallest element in an unsorted array using randomisation. It's similar to Quick Sort but only recursively searches one partition.

Pseudocode

RANDOMIZED-SELECT(A, p, r, i)
    if p == r
        return A[p]
    q = RANDOMIZED-PARTITION(A, p, r)
    k = q - p + 1
    if i == k
        return A[q]
    elseif i < k
        return RANDOMIZED-SELECT(A, p, q-1, i)
    else
        return RANDOMIZED-SELECT(A, q+1, r, i-k)

Analysis

  • Worst Case: O(n²)
  • Average Case: O(n)
  • Space Complexity: O(log n)
  • Use Case: Finding median and k-th order statistics

3. Monte Carlo Method

Probabilistic: O(n)

Description

Uses random sampling to estimate numerical values or probabilities. Particularly useful for complex numerical problems and simulating probability distributions.

Pseudocode

MONTE-CARLO-SIMULATION(iterations)
    successes = 0
    for i = 1 to iterations
        x = RANDOM(0, 1)
        y = RANDOM(0, 1)
        if x² + y² ≤ 1
            successes = successes + 1
    estimate = 4 * successes / iterations
    return estimate

Analysis

  • Accuracy: Improves with more iterations
  • Error Bound: O(1/√n)
  • Applications: π estimation, integration, sampling
  • Advantage: Easy to parallelize and scale

4. Las Vegas Algorithm (Randomised Shuffle)

Average: O(n)

Description

Fisher-Yates shuffle algorithm generates a random permutation of an array. Always produces correct result but runtime varies.

Pseudocode

RANDOMIZE-IN-PLACE(A)
    n = A.length
    for i = 1 to n
        j = RANDOM(i, n)
        exchange A[i] with A[j]
    return A

Analysis

  • Time Complexity: O(n)
  • Space Complexity: O(1)
  • Correctness: Guaranteed uniform distribution
  • Application: Shuffling arrays for lottery simulation

5. Randomised Karger's Algorithm

Average: O(n²)

Description

A randomised algorithm for finding minimum cuts in a graph. While primarily for graph problems, it demonstrates probabilistic reasoning applicable to optimization problems.

Pseudocode

KARGER-MIN-CUT(G)
    while G has more than 2 vertices
        Choose edge (u, v) uniformly at random
        Merge u and v into single vertex
        Remove self-loops
    return the two remaining supernodes

Analysis

  • Probability of Success: At least 1/n²
  • Repetitions Needed: O(n²) for high probability
  • Advantage: Simple elegant approach to hard problem
  • Use: Min-cut, network reliability

Key Concepts in Randomised Algorithms

Las Vegas Algorithms

Always produce correct results but have randomised running time. Example: Randomised Quick Sort.

Monte Carlo Algorithms

Have deterministic running time but produce correct results with high probability. Used for approximations.

Probabilistic Analysis

Analyzes expected running time over all possible random choices for worst-case inputs.

Random Number Generation

Pseudo-random generators provide uniformly distributed values essential for algorithm correctness.
